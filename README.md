# ⭕️❌ 三目並べ (Tic-Tac-Toe)

シンプルなブラウザ向け三目並べゲームです。
3人のチーム開発で作成しました。

## 現在の機能

* **2人対戦モード**: 同じ画面で交互に石（X / O）を置いて対戦できます。
* **勝敗・引き分け判定**: 縦・横・斜めのいずれかが揃うか、マスが全て埋まると結果を表示します。
* **再戦機能**: スコアや状態をリセットし、すぐに次のゲームを始められます。

## 今後の実装予定

今後のアップデートで以下の機能を追加予定です。

- [ ] **セーブ機能**: `localStorage` を活用し、ページを閉じても前回の続きから遊べるようにする。
- [ ] **CPU対戦モード**: 1人でも遊べるようにコンピュータの対戦ロジックを実装する。
- [ ] **アニメーションの追加**: 石を置いた時や勝利時に、CSSを使ったリッチな演出を加える。
- [ ] **Ultimate Tic-Tac-Toe**: さらに高度なルールの「究極の三目並べ」モードを実装する。

## 使用技術

* **フロントエンド**: HTML5, CSS3, JavaScript (Vanilla JS)
* **CSSフレームワーク**: Bootstrap (UIのレイアウトに使用)
